# Kaiju-fight

A turn-based console battle game where you pick a Godzilla-universe monster and fight a random opponent.

## What it uses
- `Scanner` to read the player's choice
- `Random` to pick the opponent and roll damage
- A `while` loop that runs the battle until one side reaches zero health
- Arrays to store the list of monsters

## How to run
1. Install the Java JDK.
2. Run `javac Main.java`, then `java Main`.
